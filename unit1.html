Topic 1

Absolute Values — The Formal Definition

The absolute value is not merely "drop the negative sign." Its correct interpretation is distance from zero on the real number line, and more generally, |x − a| is the distance between x and a. Every ε-δ and ε-N argument in analysis is secretly a statement about distances.

Definition — Absolute Value
Piecewise, algebraic, and distance definitions
Piecewise: |x| = x if x ≥ 0, and |x| = −x if x < 0.

Algebraic: |x| = √(x²) — always non-negative.

Distance (operative in analysis): |x − a| is the distance between x and a. When you read |x − a| < δ, think: "x is within distance δ of a." This is the lens through which every limit proof is read.
Key Properties of Absolute Value
|x| ≥ 0 for all x ∈ ℝ, with |x| = 0 ⟺ x = 0 |xy| = |x|·|y| (multiplicativity) |x/y| = |x|/|y| (y ≠ 0) |x − a| < r ⟺ a − r < x < a + r (open interval of radius r about a) |x − a| ≤ r ⟺ a − r ≤ x ≤ a + r (closed interval)

The Interval Characterization — Why It Matters

The equivalence |x − a| < r ⟺ x ∈ (a−r, a+r) is the most-used fact in all of first-year analysis. It translates between the algebraic language of absolute values and the geometric language of intervals. Every ε-δ proof is really an interval-shrinking argument.

Worked Example — Bounding |f(x)| using Triangle Inequality
Given |x − 2| < 1, find an upper bound for |x² − 4|.
Factor: |x² − 4| = |x − 2| · |x + 2|
Bound |x+2|: from |x−2| < 1 we get 1 < x < 3, so x+2 ∈ (3,5), thus |x+2| < 5
Therefore: |x² − 4| < 1 · 5 = 5 whenever |x − 2| < 1
This "bounding the nearby factor" trick is used in virtually every ε-δ proof for non-linear functions.
Topic 2

The Triangle Inequality

The triangle inequality is the single most-used tool in analysis after the definition of absolute value. Named for the geometric fact that "the length of any side of a triangle is at most the sum of the other two sides," it controls the absolute value of sums.

Theorem — Triangle Inequality I
|a + b| ≤ |a| + |b|
For all a, b ∈ ℝ. The absolute value of a sum never exceeds the sum of the absolute values. Generalizes to: |a₁ + ··· + aₙ| ≤ |a₁| + ··· + |aₙ|.
Proof — Triangle Inequality IDirect, from interval property
For any real x, −|x| ≤ x ≤ |x|. Apply to both a and b:
  −|a| ≤ a ≤ |a|    and    −|b| ≤ b ≤ |b|

Adding these: −(|a|+|b|) ≤ a+b ≤ |a|+|b|

This is exactly the interval condition |a+b| ≤ |a|+|b|. □
Theorem — Triangle Inequality II (Reverse)
||a| − |b|| ≤ |a − b|
The absolute difference of the magnitudes is bounded by the distance between the numbers. Used to argue: if a is close to b, then |a| is close to |b|. In analysis: if xₙ → L, then |xₙ| → |L|.
Proof — Reverse Triangle InequalityTwo applications of TI I
By TI I: |a| = |(a−b) + b| ≤ |a−b| + |b|, so |a| − |b| ≤ |a−b|.
Symmetrically: |b| − |a| ≤ |b−a| = |a−b|.

Both |a|−|b| ≤ |a−b| and −(|a|−|b|) ≤ |a−b| hold simultaneously,
which is precisely ||a|−|b|| ≤ |a−b|. □

Strategic Use of the Triangle Inequality

In proofs you often need to bound |f(x) − L| where f is a sum or product. The key technique: split the expression and bound each piece separately. For example, to bound |(aₙ + bₙ) − (A + B)|:

Standard Splitting Technique
|(aₙ + bₙ) − (A + B)| = |(aₙ − A) + (bₙ − B)| ≤ |aₙ − A| + |bₙ − B| (Triangle Inequality I) < ε/2 + ε/2 = ε (choosing N for each)

This is the skeleton of the proof that limits of sums equal the sum of limits.

Topic 3

Sequences and the ε-N Definition of a Limit

A sequence is a function a : ℕ → ℝ — an ordered, infinite list of real numbers (a₁, a₂, a₃, …). The central question: does the sequence converge? Intuition says "gets closer and closer to L," but intuition alone is insufficient. What does "closer and closer" mean precisely?

Definition — Convergence of a Sequence (ε-N)
lim(n→∞) aₙ = L
(aₙ) converges to L ∈ ℝ if:

∀ ε > 0, ∃ N ∈ ℕ such that ∀ n > N : |aₙ − L| < ε

Unpacked: no matter how small a tolerance ε you name, there is a "tail index" N such that every term beyond N is within distance ε of L. The sequence eventually (and permanently) enters any ε-neighborhood of L.

Reading the Quantifiers

The order of quantifiers matters enormously. The ∀ε … ∃N structure means: the challenger picks ε first, then you must produce a valid N. You cannot choose ε yourself — you must handle every positive ε the challenger might give you.

Proof — lim(n→∞) 1/n = 0ε-N, canonical example
Scratch work (private, find N): Need |1/n − 0| = 1/n < ε. This requires n > 1/ε. So choose N = ⌈1/ε⌉.

Formal proof: Let ε > 0. Choose N = ⌈1/ε⌉ (the ceiling of 1/ε; this is a natural number with N ≥ 1/ε). For any n > N:
  n > N ≥ 1/ε
  ⟹ 1/n < ε
  ⟹ |1/n − 0| < ε. ✓ □
Proof — lim(n→∞) (3n+1)/(n+2) = 3ε-N, rational sequence
Scratch work:
|(3n+1)/(n+2) − 3| = |(3n+1 − 3n−6)/(n+2)| = |−5/(n+2)| = 5/(n+2)
Need: 5/(n+2) < ε ⟹ n+2 > 5/ε ⟹ n > 5/ε − 2.
Choose N = ⌈5/ε⌉ (safe: N ≥ 5/ε − 2 since N ≥ 5/ε > 5/ε − 2).

Formal proof: Let ε > 0. Set N = ⌈5/ε⌉. For n > N:
  n > N ≥ 5/ε, so n+2 > 5/ε, so 5/(n+2) < ε.
  Thus |(3n+1)/(n+2) − 3| = 5/(n+2) < ε. ✓ □

Proof-Writing Template

ε-N Proof Template
Step 0. Scratch work: compute |aₙ − L| and simplify to a function of n. Step 1. Find N: solve |aₙ − L| < ε for n, getting n > f(ε). Set N = ⌈f(ε)⌉. Step 2. Formal proof: "Let ε > 0. Set N = ⌈f(ε)⌉. Let n > N. Then: |aₙ − L| = [simplified expression] < ε. □"

Practice Problems

01Solve and interpret: |2x − 8| ≤ 6. Express as an interval and describe geometrically.Easy▾
|2(x−4)| ≤ 6 → 2|x−4| ≤ 6 → |x−4| ≤ 3 → −3 ≤ x−4 ≤ 3 → 1 ≤ x ≤ 7. Solution: x ∈ [1,7]. Geometrically: all points within distance 3 of x = 4 on the number line.
02Use the Triangle Inequality to prove: |a² − b²| ≤ (|a|+|b|)|a−b|.Medium▾
Factor: |a²−b²| = |a+b||a−b|. By TI I: |a+b| ≤ |a|+|b|. So |a²−b²| = |a+b||a−b| ≤ (|a|+|b|)|a−b|. □
03ε-N proof: Prove lim(n→∞) n/(n²+1) = 0.Medium▾
|n/(n²+1) − 0| = n/(n²+1) ≤ n/n² = 1/n (since n²+1 > n²). Need 1/n < ε: choose N = ⌈1/ε⌉. For n > N: n/(n²+1) ≤ 1/n < 1/N ≤ ε. □
04ε-N proof: Prove lim(n→∞) (2n²−1)/(n²+3) = 2.Hard▾
|(2n²−1)/(n²+3) − 2| = |2n²−1−2n²−6|/(n²+3) = 7/(n²+3) ≤ 7/n². Choose N = ⌈√(7/ε)⌉. For n > N: 7/n² < 7/N² ≤ ε. □
05True/False with justification: If |aₙ − L| < ε for all n ≥ 1, does it follow that lim aₙ = L?Hard▾
YES — this is actually stronger than the definition requires. The definition asks for the condition to hold only for n > N (some N depending on ε); here it holds for all n ≥ 1. If |aₙ − L| < ε for all n ≥ 1 and every ε > 0, then in particular for any ε > 0, choose N = 1, and the condition is satisfied. So lim aₙ = L.

Question 1 — Multiple Choice
Which of the following is the correct negation of the statement "lim(n→∞) aₙ = L"?
Watch out: the negation flips ALL quantifiers. The most common error is only negating the last part.
A∃ ε > 0 such that ∀ N ∈ ℕ, ∃ n > N with |aₙ − L| ≥ ε
B∀ ε > 0, ∃ N ∈ ℕ such that ∃ n > N with |aₙ − L| ≥ ε
C∃ ε > 0 such that ∀ N ∈ ℕ, ∃ n > N with |aₙ − L| ≥ ε
D∀ ε > 0, ∀ N ∈ ℕ, ∃ n > N with |aₙ − L| ≥ ε
Correct! The original statement is ∀ε ∃N ∀n>N: |aₙ−L|<ε. Negating flips every quantifier and negates the conclusion: ∃ε ∀N ∃n>N: |aₙ−L|≥ε. This says: there is some fixed tolerance ε such that no matter how far out you go (any N), you can always find a term beyond N that escapes the ε-band. Option A and C look identical — C is the correct formal negation.
Question 2 — Multiple Choice
Let aₙ = (−1)ⁿ/n. Which statement is true?
Don't confuse |aₙ| → 0 with something about the sequence's sign pattern.
AThe sequence diverges because it alternates sign.
Blim(n→∞) aₙ = 0, because |(−1)ⁿ/n − 0| = 1/n → 0.
CThe sequence converges to 1 because (−1)ⁿ oscillates about 1.
DThe sequence converges to 0 only for even n.
Correct! B is right. The ε-N condition only requires |aₙ − L| < ε; the sign of aₙ is irrelevant. Since |(−1)ⁿ/n| = 1/n → 0, the sequence converges to 0 regardless of alternation. A is a common trap: alternating sign does NOT cause divergence by itself — the magnitudes must fail to settle.
Question 3 — Multiple Choice
In an ε-N proof that lim aₙ = L, you have found that |aₙ − L| ≤ 3/n². Which choice of N suffices for a general ε > 0?
You need 3/n² < ε. Be careful: N must be a natural number and you need n > N (not n ≥ N).
AN = ε/3
BN = 3/ε
CN = ⌈√(3/ε)⌉
DN = ⌈3/ε⌉
Correct! We need 3/n² < ε, i.e., n² > 3/ε, i.e., n > √(3/ε). So N = ⌈√(3/ε)⌉ works: for n > N, we have n > √(3/ε), so n² > 3/ε, so 3/n² < ε. Option D (N = ⌈3/ε⌉) is wrong — it would give 3/n < ε, not 3/n².

Question 4 — Short Answer
Solve: |3x − 6| < 9. Write your answer as an interval in the form (a, b).
Answer: (−1, 5). Work: |3(x−2)| < 9 → 3|x−2| < 9 → |x−2| < 3 → −3 < x−2 < 3 → −1 < x < 5.
Question 5 — Short Answer
What is the smallest valid choice of N (as a natural number) in an ε-N proof that lim(n→∞) 5/n = 0, when ε = 0.01?
N = 500. We need 5/n < 0.01, so n > 5/0.01 = 500. The smallest natural number N such that all n > N satisfy this is N = 500.

Question 6 — Long Answer (Proof)
Prove rigorously using the ε-N definition: lim(n→∞) (4n − 3)/(2n + 1) = 2.
Model Solution
Scratch work:
|(4n−3)/(2n+1) − 2| = |(4n−3 − 2(2n+1))/(2n+1)| = |(4n−3−4n−2)/(2n+1)| = |−5/(2n+1)| = 5/(2n+1)

Need: 5/(2n+1) < ε. This holds when 2n+1 > 5/ε, i.e., n > (5/ε − 1)/2.
Choose N = ⌈5/(2ε)⌉ (safe: for n > N, certainly 2n > 5/ε − 1).

Formal proof:
Let ε > 0. Set N = ⌈5/(2ε)⌉. Let n > N. Then:
n > N ≥ 5/(2ε), so 2n > 5/ε, so 2n+1 > 5/ε, so 5/(2n+1) < ε.
Therefore |(4n−3)/(2n+1) − 2| = 5/(2n+1) < ε. □
Question 7 — Long Answer (Triangle Inequality + Bound)
Let f(x) = x³. Given |x − 1| < 1/2, find an explicit upper bound for |f(x) − 1| = |x³ − 1|. Show all steps of your bounding argument clearly.
Model Solution
Step 1 — Factor: x³ − 1 = (x−1)(x² + x + 1), so |x³ − 1| = |x−1| · |x² + x + 1|.

Step 2 — Bound |x² + x + 1|: From |x−1| < 1/2 we get 1/2 < x < 3/2.
• x² < (3/2)² = 9/4
• x < 3/2
• 1 = 1
So |x² + x + 1| ≤ x² + x + 1 < 9/4 + 3/2 + 1 = 9/4 + 6/4 + 4/4 = 19/4.

Step 3 — Combine:
|x³ − 1| = |x−1| · |x² + x + 1| < (1/2) · (19/4) = 19/8.

Therefore |x³ − 1| < 19/8 whenever |x − 1| < 1/2.
