Topic 1

The Mean Value Theorem

The MVT is arguably the most important theorem in differential calculus. Its statement is deceptively simple — there must be a point where the instantaneous rate equals the average rate — but its applications as a proof tool are extraordinarily powerful.

Theorem — Rolle's Theorem
If f(a) = f(b), then f'(c) = 0 for some c ∈ (a,b)
If f is continuous on [a,b], differentiable on (a,b), and f(a)=f(b), then ∃ c∈(a,b) with f'(c)=0. Proof: by EVT, f has a max and min on [a,b]. If both are at endpoints, f is constant and f'≡0. Otherwise one extremum is interior; by Fermat's Theorem, f'=0 there. □
Theorem — Mean Value Theorem (MVT)
∃ c ∈ (a,b) such that f'(c) = [f(b) − f(a)] / (b − a)
If f is continuous on [a,b] and differentiable on (a,b), then ∃ c∈(a,b) such that f'(c) = (f(b)−f(a))/(b−a).

Geometrically: there is a point on the curve where the tangent is parallel to the secant through (a,f(a)) and (b,f(b)).

Proof — MVT from Rolle's TheoremAuxiliary function construction
Define h(x) = f(x) − f(a) − [(f(b)−f(a))/(b−a)]·(x−a). (This is f minus the secant line.)

h(a) = 0.   h(b) = f(b)−f(a)−(f(b)−f(a)) = 0. So h(a)=h(b).
h is continuous on [a,b] and differentiable on (a,b) (from f).

By Rolle's Theorem: ∃ c∈(a,b) with h'(c)=0.
h'(x) = f'(x) − (f(b)−f(a))/(b−a).
h'(c)=0 ⟹ f'(c) = (f(b)−f(a))/(b−a). □

MVT as a Proof Tool — Three Canonical Applications

Corollary 1 — Zero Derivative = Constant
f' ≡ 0 on (a,b) ⟹ f is constant
For any x₁<x₂ in (a,b): MVT gives f(x₂)−f(x₁)=f'(c)(x₂−x₁)=0. So f(x₁)=f(x₂) for all x₁,x₂. □
This justifies the "+C" in antidifferentiation.
Corollary 2 — MVT Inequality
|f'(x)| ≤ M ⟹ |f(x)−f(y)| ≤ M|x−y| (Lipschitz)
Apply MVT: f(x)−f(y)=f'(c)(x−y) for some c between x and y. Take absolute values: |f(x)−f(y)| = |f'(c)||x−y| ≤ M|x−y|. □ This is the Lipschitz condition and shows bounded derivative implies controlled variation.
Corollary 3 — Monotonicity from Derivative Sign
f' > 0 on (a,b) ⟹ f strictly increasing
For x₁<x₂ in (a,b): MVT gives f(x₂)−f(x₁)=f'(c)(x₂−x₁)>0·(x₂−x₁)>0. So f(x₁)<f(x₂). □
MVT Proof — sin(x) < x for x > 0
Prove sin(x) < x for all x > 0.
Let f(t) = t − sin(t). f(0)=0. f'(t) = 1 − cos(t) ≥ 0, with equality only at isolated points.
By Corollary 3: f is strictly increasing on (0,∞).
For x>0: f(x) > f(0) = 0 ⟹ x − sin(x) > 0 ⟹ sin(x) < x. □
MVT Proof — Uniqueness of Roots
Prove f(x) = x³ + 2x − 1 has exactly one real root.
Existence: f(0)=−1<0, f(1)=2>0. By IVT, ∃ root in (0,1).
Uniqueness: f'(x) = 3x²+2 > 0 for all x. By Corollary 3, f is strictly increasing.
A strictly increasing function equals any value at most once. So f has exactly one root. □
Topic 2

Indeterminate Forms & L'Hôpital's Rule

An indeterminate form is an expression like 0/0 or ∞/∞ where the value of the limit is not determined by the form alone — it depends on the relative rates of the numerator and denominator. L'Hôpital's Rule provides a systematic method.

Theorem — L'Hôpital's Rule
For 0/0 or ∞/∞: lim f/g = lim f'/g'
If lim(x→a) f(x)/g(x) gives 0/0 or ±∞/±∞, and f,g are differentiable near a with g'(x)≠0, then:

lim(x→a) f(x)/g(x) = lim(x→a) f'(x)/g'(x)

provided the right side exists (or is ±∞). The rule may be applied repeatedly. Also holds for x→a⁺, x→a⁻, x→±∞.
All Seven Indeterminate Forms — Identification & Strategy
Form Arises from Strategy ────────────────────────────────────────────────────── 0/0 f→0, g→0 Apply L'Hôpital directly ∞/∞ f,g→∞ Apply L'Hôpital directly 0·∞ f→0, g→∞ Rewrite: f·g = f/(1/g) → 0/0, or g/(1/f) → ∞/∞ ∞−∞ both→∞ Combine fractions, factor, or multiply by conjugate 0⁰ fᵍ, f→0⁺, g→0 Write e^[g·ln f]; exponent: g·ln(f) is 0·(−∞) → use 0·∞ strategy 1^∞ fᵍ, f→1, g→∞ Write e^[g·ln f]; exponent: g·(f−1) is ∞·0 → use 0·∞ strategy ∞⁰ fᵍ, f→∞, g→0 Write e^[g·ln f]; exponent: 0·∞ → use 0·∞ strategy
Example 1 — 0/0 (applied twice)
Evaluate lim(x→0) (eˣ − 1 − x)/x².
Form: 0/0. L'Hôpital: lim (eˣ−1)/(2x). Still 0/0.
L'Hôpital again: lim eˣ/2 = 1/2.
Example 2 — 0·∞ form
Evaluate lim(x→0⁺) x·ln(x).
Form: 0·(−∞). Rewrite: x·ln(x) = ln(x)/(1/x) → ∞/∞ form.
L'Hôpital: lim (1/x)/(−1/x²) = lim(−x) = 0.
Example 3 — 1^∞ form (definition of e)
Evaluate lim(x→∞) (1 + 1/x)ˣ.
Form: 1^∞. Let L=lim(1+1/x)ˣ. Then ln L = lim x·ln(1+1/x).
Form 0·∞ → rewrite: ln(1+1/x)/(1/x). As x→∞ this is 0/0.
L'Hôpital: lim [−1/(x²(1+1/x))] / (−1/x²) = lim 1/(1+1/x) = 1.
ln L = 1, so L = e. (This recovers the definition of e.) □
Example 4 — ∞ − ∞ form
Evaluate lim(x→1) [1/ln(x) − 1/(x−1)].
Form: ∞−∞. Combine: [(x−1) − ln(x)] / [(x−1)ln(x)]. Now 0/0 form.
L'Hôpital: [1−1/x] / [ln(x) + (x−1)/x]. Still 0/0 at x=1.
L'Hôpital again: [1/x²] / [1/x + 1/x + 1/x²]. At x=1: 1/2.

Apply MVT to f(x)=sin(x) on [a,b] (or [b,a]): sin(a)−sin(b)=cos(c)(a−b) for some c. So |sin(a)−sin(b)|=|cos(c)||a−b|≤1·|a−b|=|a−b|. □

Let L=lim xˣ. ln L=lim x·ln(x). Form 0·(−∞)=ln(x)/(1/x)→∞/∞. L'Hôpital: (1/x)/(−1/x²)=−x→0. So ln L=0, L=e⁰=1.

Question 1
The MVT requires that f be continuous on [a,b] and differentiable on (a,b). What breaks if f is differentiable on [a,b] but you drop the continuity on [a,b] assumption?
Is differentiability on (a,b) stronger than continuity on (a,b)?
ANothing breaks — differentiability on (a,b) implies continuity on (a,b), so the theorem still holds.
BNothing breaks — but you still need continuity at the endpoints a and b. Differentiability on the open interval doesn't guarantee this.
CThe theorem requires continuity on all of [a,b] and differentiability on [a,b]; they're both needed separately.
DNothing breaks — differentiability everywhere implies the MVT works.
Correct! B. Differentiability on (a,b) does imply continuity on (a,b). But continuity at the endpoints a and b must be assumed separately — differentiability on the open interval tells us nothing about behaviour at the boundary. The MVT requires f to be continuous on the entire closed interval [a,b].
Question 2
lim(x→∞) x·e^(−x) is what indeterminate form, and how should you rewrite it?
A0/0 — already in the right form for L'Hôpital.
B∞·0 — rewrite as x/eˣ to get ∞/∞, then apply L'Hôpital.
C∞·0 — rewrite as eˣ/x to get ∞/∞.
D∞/∞ — already in the right form.
Correct! B. As x→∞: x→∞ and e^(−x)→0, giving ∞·0. Rewrite as x·(1/eˣ) = x/eˣ → ∞/∞. L'Hôpital: lim 1/eˣ = 0. Option C would give lim eˣ/x → ∞, the wrong limit entirely.
Question 3
You want to evaluate lim(x→1) (x^5 − 1)/(x − 1) using L'Hôpital. A classmate says "just factor x⁵−1 = (x−1)(x⁴+x³+x²+x+1) and cancel." Who is right?
AL'Hôpital — algebraic factoring is not rigorous.
BBoth methods are correct and give the same answer (5). Factoring is often simpler.
CThe classmate — L'Hôpital requires computing derivatives, which is harder here.
DNeither — direct substitution gives 0/0, so the limit doesn't exist.
Correct! B. Both methods are valid. Factoring: (x−1)(x⁴+x³+x²+x+1)/(x−1) → x⁴+x³+x²+x+1 → 5 at x=1. L'Hôpital: lim 5x⁴/1 = 5. A 0/0 form doesn't mean the limit doesn't exist (D) — it just means direct substitution fails.

Question 6 — MVT Proof
Use the Mean Value Theorem to prove: if f is differentiable on ℝ with |f'(x)| ≤ 5 for all x, then |f(x) − f(y)| ≤ 5|x − y| for all x, y ∈ ℝ. (This is the Lipschitz condition.)
Model Solution
Setup: Let x, y ∈ ℝ with x ≠ y (WLOG x < y; the case y < x is symmetric).

Apply MVT: f is continuous on [x,y] and differentiable on (x,y). By the MVT, ∃ c ∈ (x,y) such that:
f(y) − f(x) = f'(c)·(y − x).

Take absolute values:
|f(y) − f(x)| = |f'(c)| · |y − x| ≤ 5 · |y − x|.

Conclusion: |f(x) − f(y)| ≤ 5|x − y| for all x, y ∈ ℝ. □
Question 7 — L'Hôpital (1^∞ form)
Evaluate lim(x→0⁺) (sin x)^(tan x). Identify the indeterminate form, state the rewriting strategy, and carry through the full computation.
Model Solution
Form: As x→0⁺: sin(x)→0⁺ and tan(x)→0. So (sin x)^(tan x) → 0⁰ — an indeterminate form.

Strategy: Let L = lim(sin x)^(tan x). Take logarithm:
ln L = lim(x→0⁺) tan(x) · ln(sin x).

This is 0·(−∞). Rewrite as:
ln(sin x) / cot(x) → −∞/∞ form.

L'Hôpital:
lim [cos(x)/sin(x)] / [−csc²(x)] = lim [cos(x)/sin(x)] · [−sin²(x)] = lim [−cos(x)·sin(x)].

As x→0⁺: −cos(0)·sin(0) = −1·0 = 0.

Conclusion: ln L = 0, so L = e⁰ = 1. □
