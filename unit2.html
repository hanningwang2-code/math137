Topic 1

Convergence, Divergence & Limit Laws

A sequence either converges to a unique real limit or it diverges. Divergence is not a single phenomenon: a sequence may grow without bound (diverge to ±∞), oscillate, or simply fail to settle near any value.

Theorem — Uniqueness of Limits
A convergent sequence has exactly one limit
If lim aₙ = L and lim aₙ = M, then L = M.

Proof: Suppose L ≠ M; take ε = |L−M|/2 > 0. Since aₙ→L, ∃N₁: n>N₁ ⟹ |aₙ−L| < ε, so aₙ < L+ε = (L+M)/2. Since aₙ→M, ∃N₂: n>N₂ ⟹ |aₙ−M| < ε, so aₙ > M−ε = (L+M)/2. For n > max(N₁,N₂): aₙ < (L+M)/2 AND aₙ > (L+M)/2 — contradiction. □
Theorem — Limit Laws for Sequences
Algebraic operations preserve limits
If lim aₙ = L and lim bₙ = M, then:
lim(aₙ ± bₙ) = L ± M  |  lim(aₙ · bₙ) = LM  |  lim(aₙ/bₙ) = L/M (M ≠ 0)  |  lim(caₙ) = cL
These follow from the ε-N definition using the Triangle Inequality splitting technique from Unit 1.
Worked Example — Showing Divergence by Contradiction
Prove (−1)ⁿ diverges.
Suppose lim(−1)ⁿ = L. Let ε = 1/2. Then ∃N: for all n > N, |(−1)ⁿ − L| < 1/2.
For n > N, both n and n+1 are > N, so |(−1)ⁿ − L| < 1/2 and |(−1)ⁿ⁺¹ − L| < 1/2.
By Triangle Inequality: 2 = |(−1)ⁿ − (−1)ⁿ⁺¹| ≤ |(−1)ⁿ − L| + |L − (−1)ⁿ⁺¹| < 1/2 + 1/2 = 1. Contradiction. □

Topic 2

The Squeeze Theorem

When a sequence is sandwiched between two others that converge to the same limit, it is forced to converge there too. This is one of the most elegant tools in analysis, enabling limit computations that would otherwise be impossible.

Theorem — Squeeze Theorem for Sequences
aₙ ≤ bₙ ≤ cₙ with aₙ,cₙ → L ⟹ bₙ → L
Suppose aₙ ≤ bₙ ≤ cₙ for all n ≥ N₀, and lim aₙ = lim cₙ = L. Then lim bₙ = L.
Proof — Squeeze Theoremε-N
Let ε > 0. Since aₙ→L: ∃N₁ such that n>N₁ ⟹ L−ε < aₙ. Since cₙ→L: ∃N₂ such that n>N₂ ⟹ cₙ < L+ε.

Let N = max(N₀, N₁, N₂). For n > N:
L − ε < aₙ ≤ bₙ ≤ cₙ < L + ε, so |bₙ − L| < ε. □
Worked Example — sin(n)/n
Prove lim(n→∞) sin(n)/n = 0.
Since |sin(n)| ≤ 1 for all n: −1/n ≤ sin(n)/n ≤ 1/n.
lim(−1/n) = 0 and lim(1/n) = 0 (proved in Unit 1).
By Squeeze Theorem: lim sin(n)/n = 0. □
Worked Example — Exponential Growth Beats Polynomial
Prove lim(n→∞) n/2ⁿ = 0.
For n ≥ 2, by the Binomial Theorem: 2ⁿ = (1+1)ⁿ ≥ C(n,2) = n(n−1)/2.
So 0 ≤ n/2ⁿ ≤ n / [n(n−1)/2] = 2/(n−1) for n ≥ 2.
lim 0 = 0 and lim 2/(n−1) = 0. By Squeeze Theorem: lim n/2ⁿ = 0. □
Topic 3

Monotone Convergence Theorem

The MCT is a profound consequence of the completeness of ℝ: every non-empty set bounded above has a supremum. It guarantees convergence without knowing the limit in advance — just establish monotonicity and boundedness.

Theorem — Monotone Convergence Theorem (MCT)
Bounded monotone sequences converge to their supremum/infimum
If (aₙ) is monotone increasing and bounded above (∃M: aₙ ≤ M for all n), then (aₙ) converges and lim aₙ = sup{aₙ : n ∈ ℕ}.
If (aₙ) is monotone decreasing and bounded below, then (aₙ) converges to inf{aₙ}.
Proof — MCT (increasing case)Completeness of ℝ
Let S = {aₙ : n ∈ ℕ}. Since (aₙ) is bounded above, by the Completeness Axiom of ℝ, L = sup S exists in ℝ.

Let ε > 0. Since L is the least upper bound, L − ε is not an upper bound of S, so ∃N with aₙ > L − ε.

Since (aₙ) is increasing: for all n > N, aₙ ≥ aₙ > L − ε.
Since L is an upper bound: aₙ ≤ L < L + ε.

So for all n > N: L − ε < aₙ ≤ L, giving |aₙ − L| < ε. Thus aₙ → L. □
Worked Example — MCT for a Recursive Sequence
Let a₁=1, aₙ₊₁ = (aₙ+2)/2. Show it converges and find the limit.
Claim: aₙ < 2 for all n. Base: a₁=1<2. Step: if aₖ<2, then aₖ₊₁=(aₖ+2)/2<(2+2)/2=2. ✓
Claim: (aₙ) is increasing. aₙ₊₁−aₙ = (aₙ+2)/2−aₙ = (2−aₙ)/2 > 0 since aₙ < 2. ✓
By MCT: L = lim aₙ exists. Taking limits in aₙ₊₁=(aₙ+2)/2: L = (L+2)/2 ⟹ 2L=L+2 ⟹ L=2.
Topic 4

Induction for Sequence Bounds & Monotonicity

The MCT requires proving boundedness and monotonicity — and for recursively defined sequences, induction is the standard tool. The template is always: prove the base case, assume the inductive hypothesis, use the recurrence to advance one step.

Principle of Mathematical Induction
Proving P(n) for all n ≥ 1
Base case: Verify P(1) directly.
Inductive step: Assume P(k) (the inductive hypothesis). Prove P(k+1) using the recurrence and P(k).
Conclusion: P(n) holds for all n ≥ 1.
Template — Proving aₙ < M for a Recursive Sequence
Given: a₁ = c, aₙ₊₁ = f(aₙ). Prove: aₙ < M for all n. Step 1. Base: verify a₁ = c < M directly. Step 2. Hypothesis: assume aₖ < M. Step 3. Show: aₖ₊₁ = f(aₖ) < M. (Use the recurrence AND the hypothesis aₖ < M.) Step 4. Conclude: aₙ < M for all n by induction.
Full Worked Example — Nested Radical Sequence
Let a₁=√2, aₙ₊₁=√(2+aₙ). Prove by induction: (i) aₙ < 2, (ii) aₙ is increasing. Then find lim aₙ.
Part (i): aₙ < 2 by induction. Base: a₁=√2≈1.414<2 ✓. Step: assume aₖ<2. Then aₖ₊₁=√(2+aₖ)<√(2+2)=√4=2 ✓.
Part (ii): increasing. Base: a₂=√(2+√2)>√(2)=a₁ ✓. Step: assume aₖ₊₁>aₖ. Then 2+aₖ₊₁>2+aₖ, so √(2+aₖ₊₁)>√(2+aₖ), i.e., aₖ₊₂>aₖ₊₁ ✓.
Limit: By MCT, L exists. L=√(2+L) ⟹ L²=2+L ⟹ L²−L−2=0 ⟹ (L−2)(L+1)=0. Since L>0, L=2.

Practice Problems

01Prove lim(n→∞) cos(n²)/√n = 0 using Squeeze Theorem.Easy▾
Since |cos(n²)| ≤ 1: −1/√n ≤ cos(n²)/√n ≤ 1/√n. Both ±1/√n → 0. By Squeeze: limit = 0. □
02Let a₁=3, aₙ₊₁=aₙ/2+1. Prove convergence and find the limit.Medium▾
aₙ₊₁−aₙ = 1−aₙ/2 < 0 iff aₙ>2. By induction aₙ>2 (base a₁=3>2; step: aₙ>2⟹aₙ₊₁=aₙ/2+1>2). Decreasing and bounded below by 2 → MCT: L exists. L=L/2+1⟹L=2.
03Prove by induction: for a₁=1, aₙ₊₁=aₙ/(aₙ+2), we have 0<aₙ≤1 for all n.Hard▾
Base: a₁=1∈(0,1] ✓. Step: assume 0<aₖ≤1. Then aₖ>0⟹aₖ+2>2>0, so aₖ₊₁=aₖ/(aₖ+2)>0. Also aₖ≤1<aₖ+2, so aₖ/(aₖ+2)<1. So 0<aₙ≤1 for all n. The sequence is decreasing (aₙ₊₁<aₙ since aₙ/(aₙ+2)<aₙ) and bounded below by 0; MCT gives convergence. Taking L=L/(L+2): L(L+2)=L ⟹ L²+L=0 ⟹ L=0.

Question 1 — Multiple Choice
The Monotone Convergence Theorem (MCT) guarantees that a sequence converges when it is:
Pay attention to whether both conditions are required, or just one.
ABounded above (no monotonicity required)
BMonotone increasing (no bound required)
CMonotone AND bounded (both conditions needed)
DMonotone decreasing (no bound needed since it can't go to +∞)
Correct! BOTH conditions are necessary. Counterexample for A: aₙ = (−1)ⁿ·n is bounded above (barely) but not convergent. Counterexample for B/D: aₙ = n is monotone increasing but unbounded and diverges to ∞. Monotone decreasing sequences can still diverge to −∞ if not bounded below.
Question 2 — Multiple Choice
To apply the Squeeze Theorem to show lim bₙ = L, you need:
Think carefully: does the bounding need to hold for ALL n, or just eventually?
Aaₙ ≤ bₙ ≤ cₙ for ALL n ≥ 1 and lim aₙ = lim cₙ = L
Baₙ ≤ bₙ ≤ cₙ for all n ≥ N₀ (some N₀) and lim aₙ = lim cₙ = L
Caₙ ≤ bₙ ≤ cₙ for all n and lim aₙ = L and lim cₙ = M with L ≤ M
Daₙ ≤ bₙ ≤ cₙ for all n and lim aₙ exists (lim cₙ not needed)
Correct! B. The squeezing only needs to hold eventually (for n ≥ N₀ for some N₀); behaviour of finitely many terms at the start doesn't affect convergence. A is slightly too restrictive (but also works). C is wrong because we need the same limit L for both bounds. D is wrong — we need both bounds to converge to the same L.
Question 3 — Multiple Choice
Suppose aₙ → L and all terms satisfy aₙ ≤ M. Can we conclude L ≤ M?
This tests whether limits preserve non-strict inequalities.
ANo — limits don't preserve inequalities.
BYes, and in fact L < M (the strict inequality is preserved).
CYes, L ≤ M (non-strict inequality is preserved, but L = M is possible).
DOnly if the sequence is monotone.
Correct! C. Limits preserve non-strict inequalities: if aₙ ≤ M for all n and aₙ → L, then L ≤ M. Proof: if L > M, take ε = (L−M)/2; eventually |aₙ−L|<ε means aₙ > L−ε = (L+M)/2 > M, contradiction. But strict inequality is NOT preserved: aₙ = 1/n < 1 for all n, yet lim aₙ = 0 < 1, not 0 < 1 becoming strict equality. Counter: aₙ = −1/n < 0 but limit = 0, which is NOT < 0.

Question 5 — Short Answer
Given a₁ = 4 and aₙ₊₁ = √(aₙ + 2), suppose the sequence converges. What is lim(n→∞) aₙ? (Exact value.)
L = (1+√13)/2 ≈ 2.30. Taking limits: L = √(L+2) ⟹ L² = L+2 ⟹ L²−L−2 = 0 ⟹ (L−2)(L+1) = 0... wait, re-check: L²=L+2 ⟹ L²−L−2=0 ⟹ L=(1±√9)/2 = (1±3)/2. So L=2 or L=−1. Since aₙ>0, L=2.

Question 6 — Long Answer (Proof)
Let a₁ = 5 and aₙ₊₁ = (aₙ + 4)/2. (a) Prove by induction that aₙ > 4 for all n. (b) Prove (aₙ) is strictly decreasing. (c) Conclude (aₙ) converges and find its limit.
Model Solution
(a) aₙ > 4 by induction. Base: a₁=5>4 ✓. Step: Assume aₖ>4. Then aₖ₊₁=(aₖ+4)/2>(4+4)/2=4 ✓.

(b) Decreasing. aₙ₊₁−aₙ = (aₙ+4)/2−aₙ = (4−aₙ)/2 < 0 since aₙ>4 (from part a). So aₙ₊₁<aₙ for all n. ✓

(c) Convergence. (aₙ) is monotone decreasing and bounded below by 4. By MCT, L = lim aₙ exists. Taking limits: L=(L+4)/2 ⟹ 2L=L+4 ⟹ L=4.
Question 7 — Long Answer (Squeeze Theorem)
Prove that lim(n→∞) (2 + (−1)ⁿ/n²) = 2 using the Squeeze Theorem. Identify your bounding sequences explicitly and verify their limits.
Model Solution
Bound: Since −1 ≤ (−1)ⁿ ≤ 1, we have −1/n² ≤ (−1)ⁿ/n² ≤ 1/n².
Adding 2:   2 − 1/n² ≤ 2 + (−1)ⁿ/n² ≤ 2 + 1/n².

Limits of bounds: lim(2 − 1/n²) = 2 − lim(1/n²) = 2 − 0 = 2. Similarly lim(2 + 1/n²) = 2.

Conclusion: By the Squeeze Theorem: lim(2 + (−1)ⁿ/n²) = 2. □
