Topic 1

The ε-δ Definition of a Limit

The ε-δ definition formalizes what it means for f(x) to approach L as x approaches a — without requiring f to be defined at a. The key asymmetry: ε is chosen by the challenger (as small as they like); δ is your response and may depend on ε.

Definition — Limit of a Function
lim(x→a) f(x) = L
∀ ε > 0, ∃ δ > 0 such that 0 < |x − a| < δ ⟹ |f(x) − L| < ε

Note 0 < |x − a|: the value at x = a is explicitly excluded. The limit is about f's behaviour near a, not at a. The challenge: given any ε, find a δ = δ(ε) that works.

Strategy for ε-δ Proofs
Step 1. Scratch work: compute |f(x)−L|, manipulate to isolate |x−a|. Step 2. If extra factors appear (non-linear f), restrict δ≤1 first to bound them. Step 3. Choose δ = min(1, ε/C) where C bounds the extra factor. Step 4. Formal proof: "Let ε>0. Set δ=… If 0<|x−a|<δ, then…"
Proof — lim(x→3) x² = 9ε-δ with bounding
Scratch work: |x²−9| = |x−3||x+3|. Need to bound |x+3|. Assume δ≤1: then |x−3|<1 ⟹ 2<x<4 ⟹ |x+3|<7. So |x²−9|<7|x−3|. For this to be <ε: |x−3|<ε/7. Choose δ=min(1,ε/7).

Formal proof: Let ε>0. Set δ=min(1,ε/7). Suppose 0<|x−3|<δ. Since δ≤1: |x+3|≤|x−3|+6<7. Therefore:
|x²−9| = |x−3|·|x+3| < δ·7 ≤ (ε/7)·7 = ε. □
Topic 2

Sequential Characterization of Limits

The sequential characterization is a bridge theorem connecting function limits to sequence limits. Its primary practical use is as a disproof tool: exhibit two sequences approaching a with different limiting function values, and the limit cannot exist.

Theorem — Sequential Characterization
lim(x→a) f(x) = L iff f(xₙ) → L for every sequence xₙ → a with xₙ ≠ a
(⟹) If lim(x→a)f(x)=L and xₙ→a with xₙ≠a, then given ε>0, ∃δ: 0<|x−a|<δ⟹|f(x)−L|<ε. Since xₙ→a, ∃N: n>N⟹|xₙ−a|<δ, so |f(xₙ)−L|<ε. Thus f(xₙ)→L.

Contrapositive (the useful direction): If ∃ two sequences xₙ→a and yₙ→a (both ≠a) with lim f(xₙ) ≠ lim f(yₙ), then lim(x→a) f(x) does NOT exist.
Worked Example — Disproving lim(x→0) sin(1/x)
Show lim(x→0) sin(1/x) does not exist.
Sequence 1: xₙ = 1/(2πn) → 0. Then sin(1/xₙ) = sin(2πn) = 0 → 0.
Sequence 2: yₙ = 1/(2πn + π/2) → 0. Then sin(1/yₙ) = sin(2πn+π/2) = 1 → 1.
0 ≠ 1. By the contrapositive of the Sequential Characterization, lim(x→0) sin(1/x) does not exist. □
Worked Example — One-Sided Limit Mismatch
Show lim(x→0) |x|/x does not exist.
xₙ = 1/n → 0⁺: f(xₙ) = 1 → 1.
yₙ = −1/n → 0⁻: f(yₙ) = −1 → −1.
Left limit = −1 ≠ 1 = right limit ⟹ limit does not exist. □
Topic 3

Fundamental Trig & Log Limits

Theorem — The Sinc Limit
lim(x→0) sin(x)/x = 1
Cannot be found by substitution. Proved by a geometric squeeze between triangle areas.
Proof — lim(x→0) sin(x)/x = 1Geometric Squeeze
For 0 < x < π/2, compare areas on the unit circle:
Area△OAB = ½sin(x)  |  Area sector = ½x  |  Area△OAT = ½tan(x)

Triangle ≤ Sector ≤ Triangle: ½sin(x) ≤ ½x ≤ ½tan(x).
Divide by ½sin(x)>0: 1 ≤ x/sin(x) ≤ 1/cos(x).
Take reciprocals: cos(x) ≤ sin(x)/x ≤ 1.

Since lim(x→0)cos(x)=1 and lim(x→0)1=1: by Squeeze, lim sin(x)/x=1. By even symmetry, the limit from the left equals 1 too. □
Fundamental Limits Reference
lim(x→0) sin(x)/x = 1 lim(x→0) (1−cos x)/x = 0 lim(x→0) (1−cos x)/x² = 1/2 lim(x→0) tan(x)/x = 1 lim(x→0) (eˣ−1)/x = 1 lim(x→0) ln(1+x)/x = 1 lim(x→∞) (1+1/x)ˣ = e (definition of e)
Worked Example — Combining Fundamental Limits
Evaluate: lim(x→0) sin(5x)/tan(3x)
Write = [sin(5x)/(5x)] · (5x) / {[tan(3x)/(3x)] · (3x)} = [sin(5x)/(5x)] / [tan(3x)/(3x)] · (5/3).
As x→0: sin(5x)/(5x) → 1 and tan(3x)/(3x) → 1.
Limit = 1/1 · 5/3 = 5/3.

02Use Sequential Characterization to show lim(x→0) x·sin(1/x) = 0.Medium▾
Let xₙ→0, xₙ≠0. |xₙ·sin(1/xₙ)| = |xₙ|·|sin(1/xₙ)| ≤ |xₙ| → 0. So f(xₙ)→0 for every such sequence. By Sequential Characterization, limit = 0. □
03Evaluate: lim(x→0) sin²(4x)/x².Medium▾
= [sin(4x)/(4x)]² · 16x²/x² = [sin(4x)/(4x)]² · 16. As x→0: [sin(4x)/(4x)]→1. Limit = 1·16 = 16.

|x²−1|=|x−1||x+1|. If δ≤1: |x−1|<1⟹0<x<2⟹|x+1|<3. Choose δ=min(1,ε/3). For 0<|x−1|<δ: |x²−1|=|x−1||x+1|<3δ≤ε. □

In the ε-δ definition of lim(x→a) f(x) = L, the condition 0 < |x−a| < δ specifically excludes x = a. This means:
What does the limit actually measure?
Af(a) must be undefined for the limit to exist.
Blim(x→a) f(x) can only equal f(a) if f is continuous.
CThe limit describes f's behaviour near a; the value f(a) (or whether it exists) is completely irrelevant to the limit.
DThe limit cannot equal f(a).
Correct! C. The 0 < condition ensures x ≠ a, making f(a) irrelevant. A limit is about approach behaviour, not the value at the point. f(a) could be undefined, defined but different from L, or equal to L — all are compatible with lim(x→a)f(x)=L.
Question 2
To disprove that lim(x→0) f(x) = L using Sequential Characterization, you need:
Read the contrapositive carefully — what exactly are you constructing?
AOne sequence xₙ→0 where f(xₙ) does not converge.
BTwo sequences where neither f(xₙ) nor f(yₙ) converge.
CTwo sequences xₙ→0 and yₙ→0 (both ≠0) where f(xₙ) and f(yₙ) converge to different limits.
DOne sequence xₙ→0 where f(xₙ) → M ≠ L (only one sequence needed).
Correct! C. Option D is tempting but wrong: finding one sequence giving M≠L only shows the limit isn't L; it doesn't show the limit doesn't exist (it could be M). To show the limit doesn't exist at all, you need two sequences approaching 0 giving different limits — proving no single L can work.
Question 3
What is lim(x→0) x²·sin(1/x)?
sin(1/x) oscillates wildly — does that necessarily cause the limit to fail?
ADoes not exist, because sin(1/x) oscillates as x→0.
B0, by the Squeeze Theorem: −x² ≤ x²sin(1/x) ≤ x².
C1, since sin(1/x)/(1/x)→1 as x→0.
DCannot be determined without knowing the rate of oscillation.
Correct! B. The x² factor "damps" the oscillation. Since |sin(1/x)| ≤ 1: −x² ≤ x²sin(1/x) ≤ x². Both bounds go to 0, so the limit is 0. The trap is A: oscillation of sin(1/x) alone doesn't prevent the product from converging if it's multiplied by something that goes to 0.

Question 6 — Long Answer (ε-δ Proof)
Prove using the ε-δ definition: lim(x→2) x³ = 8. You must carefully bound the non-linear factor. Show all scratch work and the formal proof.
Model Solution
Scratch work: x³−8 = (x−2)(x²+2x+4). Need to bound |x²+2x+4|. Assume δ≤1: then 1<x<3, so x²<9, |2x|<6, so x²+2x+4 < 9+6+4=19. Thus |x³−8|<19|x−2|. For 19|x−2|<ε: |x−2|<ε/19. Choose δ=min(1,ε/19).

Formal proof: Let ε>0. Set δ=min(1,ε/19). Suppose 0<|x−2|<δ. Since δ≤1: 1<x<3, so x²+2x+4 ≤ 9+6+4=19. Therefore:
|x³−8| = |x−2|·|x²+2x+4| < δ·19 ≤ (ε/19)·19 = ε. □
Question 7 — Long Answer (Disproof)
Let f(x) = x/|x| for x ≠ 0. Use the Sequential Characterization to prove that lim(x→0) f(x) does not exist. Be explicit about your two sequences and their function values.
Model Solution
Suppose for contradiction that lim(x→0) f(x) = L for some L.

Sequence 1: xₙ = 1/n > 0. Then xₙ → 0 and f(xₙ) = (1/n)/|1/n| = 1 → 1. So L must equal 1.

Sequence 2: yₙ = −1/n < 0. Then yₙ → 0 and f(yₙ) = (−1/n)/|−1/n| = −1 → −1. So L must equal −1.

But 1 ≠ −1, so no single L can equal both. By the contrapositive of the Sequential Characterization, lim(x→0) f(x) does not exist. □
