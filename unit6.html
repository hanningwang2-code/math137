Topic 1

Newton's Method

Newton's Method finds roots of f by replacing the curve with its tangent line and finding where that crosses zero. Each iteration refines the estimate — under good conditions, the error roughly squares each step (quadratic convergence).

Algorithm — Newton's Method
xₙ₊₁ = xₙ − f(xₙ)/f'(xₙ)
Starting from initial guess x₀ near a root, each iterate is the x-intercept of the tangent line at (xₙ, f(xₙ)).

Derivation: Tangent at xₙ: y − f(xₙ) = f'(xₙ)(x−xₙ). Set y=0: x = xₙ − f(xₙ)/f'(xₙ).

Failure modes: f'(xₙ)=0 (horizontal tangent); x₀ far from root (converges to wrong root or diverges); multiple roots close together.

Worked Example — Approximating √2
Use Newton's Method with x₀=1 to approximate √2 (2 iterations).
f(x)=x²−2, f'(x)=2x. xₙ₊₁ = xₙ − (xₙ²−2)/(2xₙ) = (xₙ + 2/xₙ)/2.
x₁ = (1+2/1)/2 = 1.5.
x₂ = (1.5+2/1.5)/2 = (1.5+1.333…)/2 = 1.4166…
True value √2 ≈ 1.41421… — already 4 decimal places accurate after 2 steps.
Topic 2

Linear Approximation

Differentiability means f looks like its tangent line under sufficient magnification. The tangent line is the best linear approximation to f near a — better than any other line through (a, f(a)).

Definition — Linearisation
L(x) = f(a) + f'(a)(x − a)
For x near a: f(x) ≈ L(x) = f(a) + f'(a)(x−a).

The error is |f(x)−L(x)| = O((x−a)²) — it goes to zero faster than (x−a) does. This is why differentiable functions are "locally linear."
Worked Example
Estimate (1.03)¹⁰ using linear approximation.
Let f(x)=(1+x)¹⁰, a=0. f(0)=1, f'(x)=10(1+x)⁹, f'(0)=10.
L(x) = 1 + 10x. At x=0.03: L(0.03) = 1 + 0.3 = 1.3.
True value: (1.03)¹⁰ ≈ 1.3439. Error ≈ 3.3% — reasonable for x=0.03.
Topic 3

Derivatives of Inverse Functions

If f is one-to-one and differentiable, its inverse f⁻¹ is also differentiable, and the derivative of f⁻¹ is determined entirely by the derivative of f. The key formula comes from differentiating f(f⁻¹(x)) = x via the Chain Rule.

Theorem — Inverse Function Derivative
(f⁻¹)'(x) = 1 / f'(f⁻¹(x))
Proof: Differentiate f(f⁻¹(x))=x via Chain Rule: f'(f⁻¹(x))·(f⁻¹)'(x)=1. Divide: (f⁻¹)'(x)=1/f'(f⁻¹(x)). □

Leibniz form: if y=f⁻¹(x) then dy/dx = 1/(dx/dy). Slopes of f and f⁻¹ are reciprocals at reflected points.
Proof — d/dx[arctan x] = 1/(1+x²)Inverse function theorem + right triangle
Let y=arctan(x), so tan(y)=x and y∈(−π/2,π/2).
Differentiate: sec²(y)·(dy/dx) = 1, so dy/dx = 1/sec²(y) = cos²(y).

From tan(y)=x and identity sec²(y)=1+tan²(y)=1+x²:
cos²(y) = 1/sec²(y) = 1/(1+x²).
So d/dx[arctan x] = 1/(1+x²). □
Standard Inverse Derivatives
d/dx[arcsin x] = 1/√(1−x²), |x|<1 d/dx[arccos x] = −1/√(1−x²), |x|<1 d/dx[arctan x] = 1/(1+x²) d/dx[arcsec x] = 1/(|x|√(x²−1)), |x|>1 d/dx[ln x] = 1/x (inverse of eˣ)

Bx is very close to a and the second derivative f''(a) is small in magnitude.

Correct! B. The error in linear approximation is approximately ½f''(c)(x−a)² for some c between x and a. D is backwards — if f'(a)=0, the linear approximation is just f(a), a constant, which is poor unless f really is flat.

Question 6 — Newton's Method
Apply Newton's Method to f(x) = x² − 5 starting from x₀ = 2. Perform 3 iterations and state how close you are to √5 after each step.
Model Solution
f(x)=x²−5, f'(x)=2x. Iteration: xₙ₊₁ = xₙ − (xₙ²−5)/(2xₙ) = (xₙ + 5/xₙ)/2.

x₁ = (2 + 5/2)/2 = (2+2.5)/2 = 2.25. Error: |2.25−√5| ≈ |2.25−2.2360679…| ≈ 0.0139.

x₂ = (2.25 + 5/2.25)/2 = (2.25+2.2222…)/2 ≈ 2.2361111. Error ≈ 0.0000432.

x₃ ≈ (2.2361111 + 5/2.2361111)/2 ≈ 2.2360679. Error ≈ 4×10⁻¹⁰.

The error roughly squares each iteration — this is quadratic convergence.
Question 7 — Inverse Derivative Derivation
Derive d/dx[arctan(x)] = 1/(1+x²) from scratch. Your proof must state the identity you use to simplify sec²(arctan x).
Model Solution
Setup: Let y = arctan(x), so tan(y) = x with y ∈ (−π/2, π/2).

Implicit differentiation: d/dx[tan(y)] = d/dx[x] ⟹ sec²(y)·(dy/dx) = 1.
So dy/dx = 1/sec²(y) = cos²(y).

Key identity: From tan(y)=x: draw a right triangle with opposite=x, adjacent=1, hypotenuse=√(1+x²). Then cos(y) = 1/√(1+x²), so cos²(y) = 1/(1+x²).

Alternatively: sec²(y) = 1 + tan²(y) = 1 + x², so 1/sec²(y) = 1/(1+x²).

Conclusion: d/dx[arctan x] = 1/(1+x²). □
