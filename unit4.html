Topic 1

Continuity — The Formal Definition

Informally, a function is continuous at a if you can draw it through a without lifting your pen. Formally, it is the coincidence of three things: the function is defined at a, the limit exists at a, and they agree. The ε-δ form is identical to the limit definition except x = a is now allowed (the 0 < condition is dropped).

Definition — Continuity at a Point (ε-δ)
f is continuous at a iff lim(x→a) f(x) = f(a)
Three simultaneous requirements:
(1) f(a) is defined.   (2) lim(x→a) f(x) exists.   (3) lim(x→a) f(x) = f(a).

ε-δ form: ∀ ε > 0, ∃ δ > 0 such that |x − a| < δ ⟹ |f(x) − f(a)| < ε.
Key difference from limit: |x−a| < δ, NOT 0 < |x−a| < δ. The point x=a is included.
Classification — Types of Discontinuity
Removable · Jump · Infinite
Removable: lim(x→a) f(x) = L exists, but either f(a) is undefined or f(a) ≠ L. "Fix" it by redefining f(a) = L.

Jump: Left and right limits exist but differ: lim(x→a⁻) f(x) ≠ lim(x→a⁺) f(x). Cannot be fixed by redefining one value.

Infinite (Essential): f(x) → ±∞ as x → a. Creates a vertical asymptote.

Proof — f(x) = x² is continuous at x=3ε-δ
Need: |x²−9| < ε whenever |x−3| < δ.
Key step: |x²−9|=|x−3||x+3|. Restrict δ≤1: then 2<x<4, so |x+3|<7. Thus |x²−9|<7|x−3|.
Choose δ=min(1, ε/7).

Formal: Let ε>0, δ=min(1,ε/7). If |x−3|<δ≤1: |x+3|<7, so |x²−9|=|x−3||x+3|<7δ≤ε. □
Topic 2

Limits at Infinity & Asymptotes

Definitions
Limits at Infinity and Infinite Limits
lim(x→∞) f(x) = L: ∀ε>0, ∃M>0 such that x>M ⟹ |f(x)−L|<ε.

lim(x→a) f(x) = +∞: ∀M>0, ∃δ>0 such that 0<|x−a|<δ ⟹ f(x)>M.

These generate the two types of asymptote: horizontal (limit at ±∞) and vertical (infinite limit).
Asymptote Classification
Vertical asymptote x=a: lim(x→a) f(x) = ±∞ Horizontal asymptote y=L: lim(x→±∞) f(x) = L Oblique asymptote y=mx+b: lim(x→∞) [f(x)−(mx+b)] = 0 For rational f(x)=P(x)/Q(x): deg P < deg Q ⟹ y=0 horizontal asymptote deg P = deg Q ⟹ y = (leading coeff P)/(leading coeff Q) deg P > deg Q ⟹ no horizontal; possible oblique
Worked Example — Complete Asymptote Analysis
Find all asymptotes of f(x) = (3x² − 1)/(x² − 4).
Vertical: x²−4=0 ⟹ x=±2. Check numerator at x=2: 3(4)−1=11≠0. So x=2 and x=−2 are vertical asymptotes.
Horizontal: equal degrees, ratio of leading coefficients = 3/1 = 3. So y=3 is a horizontal asymptote (both sides).
Verify: lim(x→∞)(3x²−1)/(x²−4) = lim(3−1/x²)/(1−4/x²) = 3/1 = 3. ✓
Topic 3

The Intermediate Value Theorem

The IVT encodes the intuition that a continuous function cannot "jump over" any value. Its proof relies on completeness of ℝ. As a tool, it is used almost exclusively to prove existence of solutions — roots, intersections, fixed points.

Theorem — Intermediate Value Theorem (IVT)
Continuous functions attain every intermediate value
Let f be continuous on [a,b] and let N be any value strictly between f(a) and f(b) (i.e. f(a)<N<f(b) or f(b)<N<f(a)). Then ∃ c ∈ (a,b) such that f(c) = N.

Zero version (most useful): If f is continuous on [a,b] and f(a)·f(b) < 0 (opposite signs), then ∃ c ∈ (a,b) with f(c) = 0.

Application 1 — Root Existence
Show x⁵ − 3x + 1 = 0 has a root in (1,2).
f(x) = x⁵−3x+1 is continuous (polynomial).
f(1) = 1−3+1 = −1 < 0.   f(2) = 32−6+1 = 27 > 0.
Since f(1)<0<f(2) and f is continuous on [1,2], by IVT ∃ c∈(1,2) with f(c)=0. □
Application 2 — Fixed Point Theorem
Let f: [0,1]→[0,1] be continuous. Prove ∃ c ∈ [0,1] with f(c) = c.
Let g(x) = f(x) − x. Then g is continuous on [0,1].
g(0) = f(0) − 0 = f(0) ≥ 0 (since f(0) ∈ [0,1]).
g(1) = f(1) − 1 ≤ 0 (since f(1) ∈ [0,1]).
If either is 0, done. Otherwise g(0)>0>g(1), and by IVT ∃ c∈(0,1) with g(c)=0, i.e. f(c)=c. □

lim(x→3)(x²−9)/(x−3) = lim(x+3) = 6 exists, but f(3) is undefined. This is a removable discontinuity. Redefine f(3)=6 to make it continuous.
02Use IVT to show cos(x) = x has at least one solution.Medium▾
Let g(x)=cos(x)−x. g is continuous. g(0)=1>0. g(π/2)=0−π/2<0. By IVT ∃c∈(0,π/2) with g(c)=0, i.e. cos(c)=c. □
03Find all asymptotes of f(x)=(2x³+1)/(x³−x).Hard▾
Vertical: x³−x=x(x−1)(x+1)=0 ⟹ x=0,1,−1. Check numerator at each: 2(0)+1=1≠0, 2(1)+1=3≠0, 2(−1)+1=−1≠0. All three are vertical asymptotes. Horizontal: equal degrees, ratio of leading coefficients = 2/1 = 2. So y=2.

Question 1
f is continuous at a if and only if lim(x→a) f(x) = f(a). Which of the following functions is continuous at x = 0?
Check all three conditions: defined, limit exists, they agree.
Af(x) = sin(1/x), f(0) = 0
Bf(x) = x·sin(1/x) for x≠0, f(0) = 0
Cf(x) = 1/x for x≠0, f(0) = 0
Df(x) = |x|/x for x≠0, f(0) = 0
Correct! B. For B: lim(x→0) x·sin(1/x) = 0 by Squeeze (Unit 2), and f(0)=0, so lim = f(0). Continuous! A fails because lim(x→0) sin(1/x) doesn't exist. C fails because lim(x→0) 1/x = ±∞. D fails because lim(x→0) |x|/x doesn't exist (left = −1, right = +1).
Question 2
The IVT says f must attain every value between f(a) and f(b). Which hypothesis is strictly necessary?
Think of a counterexample: what breaks if you remove "continuous" or "closed interval"?
Af must be differentiable on (a,b).
Bf must be monotone on [a,b].
Cf must be continuous on the closed interval [a,b].
Df must satisfy f(a) < f(b) (increasing).
Correct! C. Continuity on [a,b] is what's required — not differentiability, not monotonicity, and the IVT works just as well for f(a)>f(b). Without continuity: define f(x)=−1 for x∈[0,1) and f(1)=1. Then f(0)=−1, f(1)=1, but f never equals 0 — the IVT fails because f is not continuous at x=1.
Question 3
If lim(x→a⁻) f(x) = lim(x→a⁺) f(x) = L but f(a) = L + 1, then:
Carefully identify which of the three continuity conditions fails.
Af has a jump discontinuity at a.
Bf has a removable discontinuity at a; redefine f(a)=L to fix it.
Cf has an infinite discontinuity at a.
Df is continuous at a because the two-sided limit exists.
Correct! B. The two-sided limit exists (=L), so this is removable — the discontinuity is only because f(a)≠L. Jump discontinuity requires the two one-sided limits to differ. Infinite discontinuity requires the limit to be ±∞. D is wrong: the existence of the limit is necessary but not sufficient for continuity — we also need f(a) = L.

Question 6 — Proof (ε-δ Continuity)
Prove using the ε-δ definition that f(x) = √x is continuous at x = 4. (Hint: multiply and divide by √x + 2.)
Model Solution
Scratch work: |√x − 2| = |√x−2|·(√x+2)/(√x+2) = |x−4|/(√x+2). For x near 4 (say x>1), √x+2 > 1, so |√x−2| = |x−4|/(√x+2) < |x−4|. Need |x−4|<ε, so take δ=ε.

Formal proof: Let ε>0. Set δ=ε. Suppose |x−4|<δ and x≥0. Then √x+2 ≥ 2 > 0, so:
|√x − 2| = |x−4|/(√x+2) ≤ |x−4|/2 < δ/2 ≤ ε.
(In fact δ=ε works with the tighter bound; δ=min(4,ε) is another safe choice.) □
Question 7 — IVT Existence Proof
Prove that the equation e^x = 3 − x has at least one real solution. Identify your function, interval, and verify the sign condition explicitly.
Model Solution
Setup: Let g(x) = eˣ − (3−x) = eˣ + x − 3. Finding a root of g is equivalent to solving eˣ = 3−x.

Continuity: g is continuous on ℝ (sum of continuous functions).

Sign change: g(0) = e⁰ + 0 − 3 = 1 + 0 − 3 = −2 < 0.
g(2) = e² + 2 − 3 = e² − 1 ≈ 6.39 > 0.

Conclusion: g(0) < 0 < g(2) and g is continuous on [0,2]. By the IVT, ∃ c ∈ (0,2) with g(c)=0, i.e. eᶜ = 3−c. □
